  AUTOMAÇÃO DE AGENDA — CONEXA SAÚDE
═══════════════════════════════════════════════════

PRÉ-REQUISITO: Node.js instalado
  → Baixe em: https://nodejs.org (versão LTS)

═══════════════════════════════════════════════════
  COMO USAR — APENAS 2 COMANDOS
═══════════════════════════════════════════════════

1. Abra o terminal nesta pasta e rode:
   npm install

2. Depois rode:
   node executar.js

O navegador vai abrir automaticamente!
Se pedir login, faça o login e pressione ENTER no terminal.
